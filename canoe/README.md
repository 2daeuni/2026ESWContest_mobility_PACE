# PACE CANoe Simulation

CANoe-based CAN communication simulation and verification for the PACE project.

## Contents
- CANoe project configuration
- CAN database (DBC)
- CAPL scripts for Pedal, Motor, Haptic, and Safety ECUs
- CANoe panels and system variables

## Purpose
- CAN message transmission and reception verification
- CAN signal and cycle time validation
- ECU communication simulation
- Risk-level-based control verification
